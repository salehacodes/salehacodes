# salehacodes — GitHub profile makeover

This package contains a ready-to-paste profile `README.md` and a short setup guide. It intentionally uses no custom/generated images. The visual style comes from restrained rose, mauve, cream and grey badges, spacing, and small decorative symbols.

## Install

1. Open your `salehacodes` profile repository: https://github.com/salehacodes/salehacodes
2. Open `README.md` and choose **Edit**.
3. Replace the existing contents with the complete contents of `README.md` in this package.
4. Commit the change to the default branch.
5. Visit https://github.com/salehacodes and check both desktop and mobile layouts.

## Suggested profile bio

`Computer Science student exploring AI/ML, data science & software engineering.`

## Suggested pinned repositories

Pin these in this order for now:

1. `GuardianHER` — hackathon-winning application prototype
2. `world-happiness-analysis` — exploratory data analysis
3. `CSCI323_Student_Dropout_Prediction` — collaborative ML project (only if GitHub still allows it to be pinned; you do not own the repository)
4. `leetcode` — coding practice

When BeeWare has a public repository with meaningful project documentation or implementation, consider pinning it near the top.

GitHub allows up to six pinned repositories and gists. You can change pins from your profile's **Customize your pins** control.

## A few deliberate choices

- The README does not list your GPA, internship, or CV-only achievements.
- BeeWare is clearly marked as in development and in the documentation/requirements phase.
- The dropout prediction project is identified as collaborative and links to the repository owned by your teammate.
- No email address is exposed.
- No contribution-snake animation or custom contribution graph is included. Your native GitHub contribution graph already appears on your profile.
- The statistics cards are optional third-party embeds. If they fail to load or you decide you dislike them, remove the two `<img>` lines under **GitHub activity** and the explanatory note beneath them.

## Before publishing

Check that:
- The GuardianHER demo link still works.
- You are comfortable publicly associating your profile with the linked team project.
- The project descriptions still accurately reflect their current status.
- The stats cards load. They are served by a community project, not GitHub itself.
